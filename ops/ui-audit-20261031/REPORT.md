# 10.31-UI.1｜全站按鈕排列與間距檢查報告

狀態：程式已修改、測試通過、**未上線**（預覽分支 `preview/ui-button-spacing`），等使用者看截圖確認。

## 檢查方法
- 實際瀏覽器（Playwright Chromium），寬度 **320／390／768／1280**。
- 自動掃描 `ops/ui-audit-20261031/scan.js`：掃描每頁可見的按鈕、連結、輸入框、選單、展開鈕，檢查：
  互相重疊、邊框相貼（<2px）、間距不足（同排 <8px、上下 <4px）、超出畫面、文字被裁切、整頁橫向溢出。
- 頁面巡覽 `ops/ui-audit-20261031/tour.cjs`：預覽模式（本機資料，不連正式庫）登入主播後台逐頁點開。
- 勳章頁與勳章彈窗需正式登入才會讀資料；用 `medal-fixtures.mjs` 直接執行 `app.js` 真正的
  `paintMedalCollection`、`showMedalPlayer`、`showOwnMedalRoom` 產生畫面（假資料），放進真實頁面與真實樣式表檢查。
- 修改前（main `4c4f14d`）與修改後用同一套腳本比對；結果 JSON 在同資料夾。

## 規範（本次寫進 `src/theme.css` 末段「10.31 spacing pass」）
- 相鄰操作至少 **8px**；間距由排版容器（`.actions`、`.pagination`、`.tabs`、`.medal-filters`、彈窗、聲瑪大廳、頁首等）提供，**沒有**用全域 `button{margin}`。
- 明確的緊湊例外（保留，報告中另列「緊湊例外」）：
  1. ⓘ 說明圓圈緊跟它說明的按鈕 6px（待播列內 2px）。
  2. 待播列（10.28-QUEUE.1／2 使用者核准）列內小按鈕 4px。
  3. 勳章卡片右上角 ! 與 ▶ 圖示固定 6px 一組。
  4. 官網入口的分段切換膠囊（未選中的按鈕沒有邊框）：已改為 8px，不再列例外。

## 修改位置
- `src/app.js`
  - 新增 `medalRoomSwitch()`：「目前主播／其他主播」放進同一個有間距的按鈕組，並標示目前所在的一邊。
  - `paintMedalCollection()`（我的勳章 → 其他主播清單）與 `showMedalPlayer()`（各主播勳章彈窗）：主播按鈕包進 `.medal-room-list`，不再直接串接。
  - `showOwnMedalRoom()`、勳章篩選重繪、錯誤時的「返回目前主播」：同樣改用按鈕組。
- `src/theme.css` 末段「10.31 spacing pass」（勳章排行榜搜尋框與「搜尋」維持同一排）：把間距規則從只限 `#app` 擴到 `#header`、所有 `dialog`、聲瑪大廳；
  修正分頁列（原本 `gap:6px!important`／曲庫 4px）、歌曲列提歌／現點、歌本／存歌列按鈕、冠歌卡按鈕、☰ 選單、聲瑪大廳頁首；
  手機寬度（≤420px）後台六個分頁改兩排三欄，「共同曲庫」不再被切字；320px 聲瑪大廳頁首 LOGO 不再壓到「回官網」。
- `index.html`（官網入口內嵌樣式）：功能切換膠囊與示範「提歌／現點」按鈕改 8px。
- 版本：`app.js`、`theme.css` 引用改 `?v=10.31-UI.1`。
