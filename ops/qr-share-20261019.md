# 公開分享與品牌 QR（本機候選，2026-10-19）

尚未部署，沒有執行正式資料庫寫入、migration、Storage、通知或對外傳訊。整合公開網址 resolver 與正式資料庫啟用由主工作處理。

## 共用介面

```js
import {createPublicShare} from './src/share-dialog.js';
const share=createPublicShare({modal,toast});
await share.open({name:'怕怕',url:'https://paparty.app/pa',kind:'streamer'});
// 大廳：{name:'聲瑪',url:已驗證的目前canonicalUrl,kind:'hall'}
// 頁面卸載：share.dispose()
```

`modal(title, html)` 使用原有 modal 並建立 `#dialog`；本模組僅綁定內部 `.public-share`。需一併載入 `src/share-dialog.css`。`open` 不複製、不呼叫裝置分享、不發送訊息；只有使用者點按後才執行。呼叫端必須依**目前瀏覽主播**取得 server canonical 公開首頁，不能使用登入者主播或目前管理頁網址。

## 程式

- `src/branded-qr.js`：H 容錯、4 module 白邊、黑白矩陣、官方 LOGO、SVG 與瀏覽器 canvas PNG。
- `src/vendor/qrcodegen.js`：Project Nayuki 1.8.0 固定版本，唯一變更是 ESM 匯出；完整 MIT 與原始資產 SHA256 在 `qrcodegen-LICENSE.txt`。來源：https://github.com/nayuki/QR-Code-generator/releases/tag/v1.8.0 。官方 API/規格：https://www.nayuki.io/page/qr-code-generator-library 。
- `src/share-dialog.js`、`.css`：同一分享視窗支援訪客、玩家、管理者；複製網址、PNG/SVG 下載、長按圖片另存替代、Web Share 圖片／文字／複製 fallback。取消分享不重試、不複製。固定 modal header/X；body 單獨捲動。
- `lobby.html`、`src/lobby-entry.js`、`src/lobby.css`、`src/lobby-public-share.js`：刪除大廳 intro 多餘小字；回官網旁小型登入與分享。沿用 portalLogin 選主播登入，不加分類。只有既有 space-001 聲瑪廳可呼叫現有 discovery，其他／不明 pretty 廳先安全阻擋，沒有預設落進聲瑪。大廳分享按下才讀 publicRouteInfo，未啟用時明確提示，無假連結。

官方 PNG 為兩版合併原稿，本模組使用現有網站 CSS 同樣的 dark-logo 裁切，直接以 nested SVG viewBox 嵌入**原始 PNG bytes**，未重新生成或重設 LOGO。中心 LOGO 寬度為 symbol 的 16%，周圍保留少量白底。版本 7–13 有中心 alignment pattern，較長網址改用 version 14–20，避免覆蓋固定辨識圖樣。即使 canvas 不支援，self-contained SVG 仍可預覽與下載。

## 針對性驗證

```text
node --test tests/branded-qr.test.js tests/share-dialog.test.js tests/lobby-public-share.test.js tests/public-lobby.test.js
```

實際解碼測試不是比對函式輸出：將產生的**完整 SVG（包含官方 PNG）**以離線 sharp rasterize 成 PNG，再由 Python OpenCV QRCodeDetector 解碼。測試 4 組公開網址（短主播首頁、廳首頁、雙段首頁、約 200 字元長網址），各測 256、512、1024px、無 LOGO／有 LOGO，共 24 組；全部還原正確的原始網址。當前環境使用已內建 sharp、Python OpenCV，無新增正式 runtime 相依。缺少這兩個離線工具的機器會明確 skip decoder 測試，不能把 skip 宣稱掃描通過。

其他測試涵蓋：query/hash/credentials/admin/subpage 分享防護、惡意顯示名稱轉義、canvas 暫存 URL 清理與 SVG fallback、clipboard 權限拒絕與選取替代、無 Web Share、不可分享圖片、使用者取消、連點防重入、關窗後延遲結果隔離、Blob URL 釋放、無假下載成功、scope 不符／尚未啟用時不造廳連結、未知廳 0 聲瑪 API、登入意圖跨分頁保留。

未聲稱驗證：真實 Android/iOS 的原生分享 chooser、相簿儲存、列印後實機掃描；不能由離線 decoder 或 mock navigator 取代這些裝置驗收。沒有透過裝置分享實際送給任何收件人。

## 流量

生成／匯出 QR 全在瀏覽器本機；官方 LOGO 只從現有網站靜態檔載入並快取。沒有 Supabase Storage、Realtime 或 polling。開啟分享只做一次 scope 明確的 publicRouteInfo（既有 client 最多 32 key、60 秒快取）；不讀玩家、帳本、歌曲全量、私人 Audit。
