# PA Party 教學中心：Claude 接手清單

## 接手目標與目前上線範圍

使用者已授權發布可用的教學基礎功能，把缺少部分交給 Claude 補齊。前端發布版為 `11.02-TUTORIAL.1`，後端維持 `11.02-CARRY.1`。請先以遠端 main 與正式 release.json 核對實際發布結果。

本次發布的是玩家／主播入口、共用面板、身分篩選及未完成教材隱藏。**13 篇文章全部仍為 draft，正式入口顯示「教材準備中」；不是已有 13 篇正式教材。** 本機既有 demo 模式可顯示有缺項標記的草稿。

## 程式與素材位置

- `src/tutorial-center.js`：獨立 dialog；分類、搜尋、步驟、章節跳轉、圖片標記、載入與錯誤、草稿隱藏。
- `src/tutorial-center.css`：只作用於教學面板，手機全螢幕、桌面限寬、深淺主題。
- `src/tutorials/index.json`：全部 13 篇索引與 status。
- `src/tutorials/P01.json` 等：逐篇教材，能獨立更新。
- `src/tutorials/images/`：25 張已處理的真實網站 WebP 截圖；不要把 demo 或重製畫面當成正式實拍。
- `src/app.js`：header 的 tutorialCenter 按鈕、後台 admin-more-options 末端按鈕、身分 callback，以及 crownHelp 的 appendRelated。
- `src/application-menu.js`、`src/application-menu-bootstrap.js`：帳號與管理分組及相容入口順序。
- `src/theme-studio.js`：問號說明開啟時發出 pa-tutorial-context，對應 S07 章節。
- `tests/tutorial-center.test.js`：身分／搜尋／素材路徑／published 審核資料檢查。
- `tests/fixtures/tutorial-qa.html`：14 項瀏覽器檢查與未送出表單保留測試。
- `tests/fixtures/admin-fixture.html`：只在 localhost 設定本機 demo 測試身分，不能用於正式登入。

## 共用功能尚缺的收尾

1. **快速教學連結尚未全部接完。**「如何冠歌」及部分主題問號已預留映射，但因文章未發布而不顯示完整教學連結。歌曲首數／額度說明框仍需接線；主題配色、圖片、遮罩、裝飾、草稿及發布說明須逐一核對。沒有對應文章時維持原狀。勳章圖鑑的每枚勳章驚嘆號不要改成獨立教材。
2. **章節連結必須驗證。** S07 現有章節 id 為字串 `1`～`5`；P03 已有 `guide`／`fees`；P01 為 `choose`／`confirm`／`fees`／`saved`。改章節時同步所有映射，不能留下無效定位。
3. **深色整合文章截圖曾有模糊現象。** 獨立測試頁圖文可讀；網站 demo 的文章截圖曾整層模糊。已確認內容沒有 filter、並隔離教學 header／backdrop 的背景濾鏡，但仍須釐清瀏覽器擷取或實際渲染。不能把此項列為完整教材驗收通過。正常上線模式目前不展示這些文章。
4. **裝飾說明有既有矛盾。** theme-studio 的裝飾問號與 src/app.js 的 syncThemeDecor／現有測試支持多頁渲染（平台管理除外）；儲存發布區末句卻寫「裝飾圖片只出現在首頁」。先以正式網站核對實際範圍，再確認教材文字；不要為配合教材擅改裝飾功能。
5. **既有匯入預覽可讀性問題。** 正式手機、電腦的重複歌曲預覽出現文字被擠到直排窄欄。本次沒有修改匯入排版或邏輯，S02 仍不可當完整教材。若要修復，維持點歌／匯入邏輯與按鈕作用，另做範圍清楚的修復。
6. **手機／電腦與實體裝置。** 本機面板曾檢查 390px 與 1280px；補完後仍須重驗深淺主題、Esc／關閉／焦點、原有 dialog 疊加、未提交表單、捲動與章節跳轉。實體手機／PWA 尚未完成驗收。

## 不應為了教材執行的正式操作

- 本次只開啟表單、查看既有資料、做匯入檢查預覽，沒有按確認匯入或儲存；沒有新增點歌、完成演唱、取消紀錄、加存歌、啟用專屬權、確認款項或發布主題。
- 不要為了拍圖自行建立正式點歌或帳務。缺少觸發狀態時，請使用使用者指定的隔離測試環境，或由使用者安排正常操作供觀察。
- 需要登入時請使用者自行登入，不索取密碼；不要切換或冒用其他玩家身分。
- 截圖先遮蔽姓名、登入 ID、私人訊息、私人註記與帳務；公眾主播名稱及歌曲資料可保留。

## 發布一篇教材的條件

1. 每個重要步驟有真實、可讀、完成遮蔽的網站截圖；配合正確的文字、按鈕作用及資料／額度／通知／權限注意事項。標記編號與位置需人工核對。
2. 逐條核對已確認規則；不能以推測或待補文字當成正式內容。保留截圖實際版本／日期，不要把舊圖的 caption 改成新版本冒充重拍。
3. 同步把 index 與文章的 `status` 改成 `published`；清空 `missing`，補 `reviewedAt`、`reviewedBy`。目前測試會檢查 published 文章每步的 image、buttons、notes，以及審核欄位。
4. 重新測試該文章及其所有入口、問號連結、指定章節、上下一步／目錄／關閉；正式模式玩家只能列玩家篇，主播只能列主播篇。
5. 教學圖片用 WebP／AVIF 靜態檔、按需載入；相同圖以同一路徑共用。圖片修改時使用新檔名。JSON 載入為 no-cache；頁面內仍有快取，驗證更新時重新載入頁面。
6. 不新增 Supabase 教學表、追蹤、影音存放、輪詢或資料庫寫入；不改點歌、計價、存歌、冠歌或權限邏輯。不新增「帶我操作」。
